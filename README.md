# Микроәлем · 3D

Үш интерактивті оқу моделі: эвглена, хламидомонада, криптофитті балдыр. Қазақша атаулар, баяу айналу, ашық кесінді. 16:9 экранға арналған.

https://milord-x.github.io/protist-atlas/

Сүйреу — айналдыру; тінтуір дөңгелегі — масштаб; Space — айналуды тоқтату; L — атаулар; R — бастапқы көрініс; F — толық экран. Қозғалысты азайту жүйелік баптауы ескеріледі.

Жергілікті іске қосу: `python -m http.server 8766`. Содан кейін `http://localhost:8766` ашыңыз. Құрастыру қажет емес. Three.js r160 жергілікті файл ретінде қамтылған, лицензиясы assets ішінде.

Тексеру: Playwright және Chromium орнатылған ортада `node check.cjs`. Басқа сайтты тексеру үшін `ATLAS_URL` айнымалысын қолданыңыз.

Терминдер мен модельдеу ескертпелері: [SOURCES.md](SOURCES.md).
